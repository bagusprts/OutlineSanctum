# OutlineSanctum

Turns complex documents into organized outlines for students and professionals who need to study and review large texts.

With OutlineSanctum, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/OutlineSanctum.git`
2. `cd OutlineSanctum`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
